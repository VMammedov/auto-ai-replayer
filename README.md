# Auto AI Replayer

Static marketing and privacy-policy site for the **Auto AI Replayer**
browser extension, published with GitHub Pages from the `docs/`
folder.

Auto AI Replayer types a "continue" reply in an AI chat after each
response, so one long prompt is answered in batches on Claude,
ChatGPT and Gemini.

Live site: https://VMammedov.github.io/auto-ai-replayer/
Privacy policy: https://VMammedov.github.io/auto-ai-replayer/privacy-policy.html

The site is plain HTML and CSS with no build step, no framework, and
no external requests (no web fonts, CDN, analytics or embeds).
